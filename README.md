# 🚗 Dashboard Penjualan Mobil Terlaris di Dunia (Kasus 3)

Aplikasi web dashboard interaktif berbasis **Streamlit** dan **Plotly** dengan antarmuka **Apple UI / macOS Style** serta dukungan **Light/Dark Mode** untuk menganalisis data penjualan mobil (`Cars Datasets 2025`).

## 🛠️ Fitur Utama
- **Theme Switcher:** Bebas memilih Mode Terang (Light Mode ☀️) atau Mode Gelap (Dark Mode 🌙).
- **Filter Interaktif:** Filter berdasarkan Rentang Tanggal, Kategori Mobil (MPV, SUV, City Car/LCGC, Electric Vehicle), dan Model Mobil (Avanza, Xpander, Innova Zenix, Brio, HR-V, Creta, Air EV).
- **KPI Metrics Cards:** Total Pendapatan, Total Mobil Terjual, Rata-rata Harga Mobil, dan Jumlah Transaksi.
- **Visualisasi Interaktif:**
  1. Tren Penjualan Mobil Harian
  2. Proporsi Kategori Mobil
  3. Total Terjual per Model Mobil
  4. Distribusi Harga Mobil
